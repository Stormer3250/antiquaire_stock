# L'Antiquaire — V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete V1 of the L'Antiquaire bar stock/costing/pricing appliance per spec v2.1 (`docs/superpowers/specs/2026-07-31-antiquaire-stock-architecture-design.md`).

**Architecture:** FastAPI (sync) + stdlib sqlite3 ledger + static vanilla-JS frontend (ES modules, no build), launchd appliance. Pure pricing/fiscal math isolated in `pricing.py`; ledger derivation in `stock.py`; routes thin.

**Tech Stack:** Python 3.12 / uv, FastAPI, uvicorn, openpyxl, pytest, ruff. Frontend: hand-written HTML/CSS/JS, vendored fonts (Playfair Display, IBM Plex Sans, IBM Plex Mono).

## Global Constraints

- Branding: **L'Antiquaire** (replaces the design's "Le Pingouin"), subtitle "Cave & comptoir", monogram "A". French UI throughout, `fr-FR` number formats, €.
- Everything synchronous; server binds `127.0.0.1:8765`, single uvicorn worker.
- Data dir `~/AntiquaireStock/` (override with env `ANTIQUAIRE_DATA_DIR` for tests): `stock.db`, `backups/`, `exports/`, `logs/`.
- SQLite: WAL, `foreign_keys=ON`; migrations via `PRAGMA user_version` + numbered SQL files; app refuses to serve on failed migration.
- No mutable stock column — ledger only (`reception`/`comptage`/`ajustement`), REAL quantities, per-location, derivation ordered by `id`.
- `droits_inclus` defaults **0** (taxes added to cost); per-ref `prix_ttc` override nullable.
- No staff, no photos, no auth, no async, no Node.
- Design reference: `design/Stock Pingouin.dc.html`. Palette: bg `#141010`, sidebar `#0F0C0C`, panel `#1A1513`, header `#171211`, borders `#2E2521`/`#221B18`, input bg `#100D0C`, text `#F2E9DC`, muted `#A2917E`/`#8B7A69`/`#6D5D4E`, accent `--ac #79A63A` / `--ac2 #9BC65C` / `--ac3 #A3C86B`, danger `#7A2B2B`/`#C9736E`, ok-panel `#1E2A12`/`#2F4A1C`, warn-panel `#2A1B1A`/`#4A2A28`.

### Task 2: pricing.py — the money engine (pure)

**Files:** `src/antiquaire/pricing.py`, `tests/test_pricing.py`

**Produces (exact signatures, all pure, no I/O):**
- `doses_per_bottle(vol_cl, dose_cl) -> float`
- `fiscal_per_dose(regime, abv, dose_cl, rates) -> Fiscal(accise, ss, hlap)` — spiritueux: `hlap = dose_cl/100/100 * abv/100`, `accise = hlap*rates['accise']`; vin: hL product × (`mousseux` rate if abv>12.4 else `vin`); mousseux/intermediaire: hL × mousseux; biere: hL × rate × abv; ss = `hlap*rates['ss']` iff abv>18; aucun/abv 0 → 0.
- `cost_per_dose(achat_ht, vol_cl, dose_cl, *, droits_inclus, regime, abv, rates) -> float` — base achat/doses, + accise+ss when not droits_inclus.
- `round_price(v, step) -> float`; `price_for_margin(cost, marge_pct, tva_pct, step) -> float` (= round(cost/(1−m)×(1+tva)))
- `real_margin(cost, prix_ttc, tva_pct) -> float`
- `ingredient_cost(ref_row, qty, category_row, rates) -> float` (tracked: cost/cl × cl incl. droits logic at bottle level scaled per cl; untracked/consommable: achat × qty)
- `cocktail_cost(ing_rows) -> float`; `suggested_cocktail_price(cost, cible, step) -> float` (TVA 20 fixed)
- `feasibility(ings_with_stock) -> (n_services, limiting_nom) | None`
- `order_suggestions(rows) -> list` grouped by fournisseur, qty = `ceil(par_target − stock)` for `stock<=seuil`
- [ ] Failing tests first: rhum 70cl/5cl = 14 doses; cost 24.90→1.7786/dose sans taxes; droits off adds accise (55° spiritueux, 1954 → hlap 5/10000×0.55=2.75e-4… assert exact values); ss boundary 18.0 vs 18.1; vin 12.4/12.5 switch; margin 80% + TVA 20 + arrondi .5 round-trips; real_margin inverse; override display math; cocktail cost w/ consommable qty 1; feasibility limiting; order ceil/grouping.
- [ ] Implement; green; commit.
